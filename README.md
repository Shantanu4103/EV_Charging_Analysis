# EV Charging Pattern Analysis | K-Means & DBSCAN

An exploratory **unsupervised machine learning** case study using Python to investigate electric-vehicle charging behavior and discover potential customer or usage segments.

## Project objective

Explore the EV charging dataset, assess charging behavior, compare **K-Means** and **DBSCAN**, and describe segments that may inform charging-infrastructure planning. The analysis is exploratory; it does **not** establish causal effects or guarantee operational improvements.

## Dataset

- Source: [Electric Vehicle Charging Patterns — Kaggle](https://www.kaggle.com/datasets/valakhorasani/electric-vehicle-charging-patterns)
- The CSV is **not included** in this repository. Download it from Kaggle, check the dataset's terms, and save it as `data/ev_charging_patterns.csv`.
- The original notebook reported 1,320 records. Re-run the updated notebook to verify the actual loaded shape and results.

## Methods

1. Audit schema, missing values, and duplicates.
2. Explore distributions and correlations.
3. Remove ID and timestamp columns; impute missing data; one-hot encode categorical fields; standardize numeric fields.
4. Compare K-Means cluster counts using inertia, silhouette score, and Davies–Bouldin index.
5. Explore DBSCAN parameters using k-nearest-neighbor distances, noise percentage, and non-noise silhouette score.
6. Visualize segments with a two-dimensional PCA projection.
7. Profile clusters in the **original measurement units** and interpret potential business applications.

## Modeling considerations

- The original project used integer mappings for charger and user types, scaled before capping outliers, and fitted K-Means on unscaled data. This version uses categorical one-hot encoding and consistent preprocessing.
- Automatic IQR outlier capping is omitted because rare usage patterns may be analytically meaningful.
- The unsupervised exploratory analysis uses the full dataset; assess cluster stability before production use.
- PCA is for visualization only; it does not change the clustering feature space.
- Silhouette-based selection is a heuristic, not proof of the correct number of segments.
